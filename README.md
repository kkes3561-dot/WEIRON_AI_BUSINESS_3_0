# WEIRON AI BUSINESS 3.0 — Render build

Flask CRM MVP with DeepSeek API. Templates and static assets are included.

## Deploy to Render

1. Upload the contents of this folder to the GitHub repository root.
2. In Render choose **New → Blueprint** to use `render.yaml`, or create a Web Service manually:
   - Build command: `pip install -r requirements.txt`
   - Start command: `gunicorn app:app`
3. Add `DEEPSEEK_API_KEY` in Render Environment. Never commit `.env` or paste the key into GitHub.
4. `SECRET_KEY` is generated by the Render Blueprint. If creating a manual Web Service, add a long random `SECRET_KEY`.

## Important limitations of the demo build

- This build uses SQLite (`weiron.db`) in the app directory. Render Free has an ephemeral filesystem: database changes can be lost after restart, redeploy, or instance replacement. Do not use this demo for real customer records.
- Render Free web services sleep after inactivity and wake on the next request. This is not guaranteed always-on 24/7 hosting.
- The current app is an MVP, not a production-secure multi-tenant SaaS. Before real use, add persistent database storage, access controls for registration, CSRF protection, rate limiting, backups, and security review.

## Local Windows run

```powershell
python -m venv .venv
.\.venv\Scripts\Activate.ps1
pip install -r requirements.txt
copy .env.example .env
# Fill DEEPSEEK_API_KEY and SECRET_KEY in .env locally
python app.py
```
